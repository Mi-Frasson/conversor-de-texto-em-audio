# Conversor de Texto em Áudio 1.0

Primeira versão pública.

### Destaques

- Converte o texto de PDFs em MP3.
- Assistente acessível de primeira execução.
- Configurações integradas ao NVDA.
- Comandos configuráveis em Gestos de entrada.
- Funciona sem instalar Python externamente.
- Janela acessível para acompanhar o progresso.

### Importante

A síntese de voz requer Internet e transmite trechos do texto ao serviço on-line de voz
utilizado pelo complemento. PDFs somente com imagens precisam de OCR.
